## 選び方
- 一般の人の暮らし・健康・薬・食品の安全・医療制度に関わり、「へえ」と思える具体的な事実（数字、日付、何が変わるか）があるものを優先。
- 会議の開催案内だけ、資料の掲載だけのものは避ける。
- 事実がPDFにある場合（統計の概要、報道発表資料など）：WebFetch でページ内のPDFリンクの完全なURLを聞き出し、
  Bash で `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/fetch_pdf.ps1 <PDFのURL>` を実行する。
  出力された `logs/pdf/xxx.txt` を Read で読む（WebFetch でPDFを直接読もうとしないこと。読めません）。
  このコマンド以外の Bash は使わない。
- 事故・死亡・事件・特定の個人や企業への批判が中心のものは選ばない。
- 候補ページを WebFetch で読み、本文に十分な事実がなければ別の候補を試す（最大4本）。どれもだめなら何も書かずに終了。

## 登場人物
- sensei（ヤク先生）：薬剤師。白衣とメガネ。落ち着いて、やさしく正確に説明する。**口調はタメ口**（「〜だよ」「〜なんだ」「〜してね」）。です・ます調は使わない。
- mina（ミナ）：一般の会社員。好奇心旺盛でリアクションが大きい。読者の代わりに素朴な疑問を言う。先生には丁寧語（「〜ですね」「〜なんですか？」）。

## 厳守ルール
1. 漫画・まとめに出す数字・日付・固有名詞は、**すべて出典ページに書かれているもの**だけ。推測や一般知識で数字を足さない。
2. 実在の個人名・企業名・商品名は出さない。国名は出典の対象を示すのに必要な場合だけ。
3. 病気・被害・特定の立場の人を笑いのネタにしない。オチは登場人物の日常の小ボケ程度に。
4. 個別の治療をすすめない。健康の判断は「医師・薬剤師に相談」で締める。
5. 文章は出典の丸写しにせず、自分の言葉で言い換える（定義の引用は短く）。

## 書式
`episodes/{{DATE}}.json` に Write ツールで、次の形の JSON を UTF-8 で書く（このファイル以外は作らない・変更しない）。

```json
{
  "date": "{{DATE}}",
  "status": "draft",
  "tag": "くすり | 食品の安全 | 医療と暮らし | 感染症 | 制度・お金 | 働く人の健康 など短く",
  "title": "28字以内の見出し",
  "source": { "publisher": "厚生労働省", "title": "出典ページのタイトル", "url": "出典URL", "published": "YYYY-MM-DD" },
  "panels": [
    {
      "bg": "pharmacy | home | office | plain | sparkle",
      "fx": "shock | gloom（任意。驚き・がっかりのコマだけ）",
      "prop": "任意。コマ中央の小さな看板に出す要点。12字×3行以内、改行は\\n",
      "chars": [ { "id": "mina", "expr": "surprised", "pos": "left" }, { "id": "sensei", "expr": "normal", "pos": "right" } ],
      "lines": [ { "who": "mina", "text": "..." }, { "who": "sensei", "text": "..." } ]
    }
  ],
  "summary": ["まとめ（事実のみ）を3〜5項目、各80字以内"],
  "comment": "ヤク先生のひとこと（100字以内）",
  "checks": [ { "claim": "漫画・まとめでの主張", "quote": "それを裏づける出典の該当箇所（原文の短い抜粋）" } ]
}
```

- panels はちょうど4つ。起（話題提示）→承（中身）→転（意外な点・注意点）→結（ほっこりオチ）。
- 各コマ chars は2人（pos は "left" と "right"）。lines は各キャラ1つまで、**左のキャラのセリフを先に**書く。
- セリフは1つ **32字以内**（短いほど読みやすい。20字前後が理想）。叫びには "style": "shout"、心の声には "style": "think" を付けてよい。
- expr は normal / smile / surprised / worried / explain / serious のどれか。prop を使うコマは2人とも配置する。
- checks には漫画とまとめに出てくる数字・日付・事実を**全部**載せる。出典にない内容（ひとことの一般論など）は quote に「出典外：〜」と書く。
- 書き終えたら Read で読み返し、JSON として正しいか、ルール1〜5を守っているか確認して終了。
